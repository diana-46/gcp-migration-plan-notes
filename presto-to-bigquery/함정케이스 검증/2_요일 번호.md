# 2. 요일 번호 — 1이 가리키는 요일이 다르다

- 검증일: 2026-09-03
- 검증자: diana (Presto: Hue/adhoc — DATE 리터럴 기반이라 세션 TZ 무관 / BigQuery: `dev-dp-project-354904`)
- 분류: ⚠ 조용히 결과가 달라지는 함정 (문법 에러 없음)

## 무엇이 다른가

| | Presto `day_of_week()` / `dow()` | BigQuery `EXTRACT(DAYOFWEEK)` |
| --- | --- | --- |
| 체계 | ISO — **1=월 ... 7=일** | **1=일 ... 7=토** |

`WHERE day_of_week(d) IN (6, 7)` (주말 필터) 같은 쿼리를 그대로 옮기면
문법 에러 없이 **금·토**를 거르게 된다.

## 검증 쿼리와 실측 결과

**Presto:**

```sql
SELECT
    day_of_week(DATE '2026-09-07')  AS mon,   -- 결과: 1 (월요일, ISO)
    day_of_week(DATE '2026-09-06')  AS sun,   -- 결과: 7 (일요일)
    dow(DATE '2026-09-07')          AS mon2   -- 결과: 1 (별칭 동일)
```

**BigQuery:**

```sql
SELECT
    EXTRACT(DAYOFWEEK FROM DATE '2026-09-07')  AS mon,   -- 결과: 2 ← 함정 본체
    EXTRACT(DAYOFWEEK FROM DATE '2026-09-06')  AS sun,   -- 결과: 1
    MOD(EXTRACT(DAYOFWEEK FROM DATE '2026-09-07') + 5, 7) + 1  AS mon_iso,  -- 결과: 1
    MOD(EXTRACT(DAYOFWEEK FROM DATE '2026-09-06') + 5, 7) + 1  AS sun_iso   -- 결과: 7
```

## 결론

1. **함정 성립**: 월요일이 presto 1 vs BQ 2. 요일 번호를 쓰는 필터/집계는 전부 영향.
2. **동치 변환식 (검증됨)**: `MOD(EXTRACT(DAYOFWEEK FROM d) + 5, 7) + 1`
   → presto `day_of_week(d)` 와 완전 동일 (월=1 ... 일=7).
3. 가독성이 중요하면 `IF(EXTRACT(DAYOFWEEK FROM d) = 1, 7, EXTRACT(DAYOFWEEK FROM d) - 1)`
   도 동치 (미실측 — 산술상 동일).
