# 3. 배열·문자열·식별자 세트 — 7종 확인 (MAP 은 재설계 확정)

- 검증일: 2026-09-03
- 검증자: diana (Presto: presto-cli UTC 세션, adhoc / BigQuery: `dev-dp-project-354904`)
## 검증 쿼리

**Presto:**

```sql
SELECT
    element_at(ARRAY[10,20,30], 2)   AS d1,
    element_at(ARRAY[10,20,30], -1)  AS d2,
    cardinality(ARRAY[10,20,30])     AS d3,
    sequence(1, 5)                   AS d4,
    regexp_like('abc123', '\d+')     AS d5,
    1                                AS "My Col",
    (SELECT array_agg(t.v) FROM UNNEST(ARRAY['a','b']) AS t(v))      AS d6_unnest_alias,
    (SELECT map_agg(k, v) FROM (VALUES ('a',1),('b',2)) AS t(k, v))  AS d7_map
;
```

**BigQuery:**

```sql
SELECT
    [10,20,30][SAFE_OFFSET(1)]                 AS d1,
    ARRAY_REVERSE([10,20,30])[SAFE_OFFSET(0)]  AS d2,
    ARRAY_LENGTH([10,20,30])                   AS d3,
    GENERATE_ARRAY(1, 5)                       AS d4,
    REGEXP_CONTAINS('abc123', r'\d+')          AS d5,
    1                                          AS `My Col`,
    ARRAY(SELECT v FROM UNNEST(['a','b']) AS v)                       AS d6_unnest_alias,
    (SELECT TO_JSON_STRING(ARRAY_AGG(STRUCT(k, v)))
     FROM (SELECT 'a' AS k, 1 AS v UNION ALL SELECT 'b', 2))          AS d7_map_substitute
```

## 실측 결과

| 컬럼 | Presto 식 → 결과 | BigQuery 식 → 결과 | 판정 |
| --- | --- | --- | --- |
| d1 | `element_at(ARRAY[10,20,30], 2)` → `20` | `[10,20,30][SAFE_OFFSET(1)]` → `20` | ✅ 동치 (1-based ↔ 0-based) |
| d2 | `element_at(..., -1)` → `30` | `ARRAY_REVERSE(...)[SAFE_OFFSET(0)]` → `30` | ✅ 음수 인덱스 대체식 검증 |
| d3 | `cardinality(...)` → `3` | `ARRAY_LENGTH(...)` → `3` | ✅ |
| d4 | `sequence(1, 5)` → `[1,2,3,4,5]` | `GENERATE_ARRAY(1, 5)` → 동일 | ✅ |
| d5 | `regexp_like('abc123', '\d+')` → `true` | `REGEXP_CONTAINS('abc123', r'\d+')` → `true` | ✅ |
| "My Col" | 더블쿼트 식별자 → 동작 | 백틱 `` `My Col` `` → 동작 | ✅ 인용 문법만 교체 |
| d6 | `UNNEST(...) AS t(v)` (테이블(컬럼) 별칭) → `[a, b]` | `UNNEST(...) AS v` (컬럼 별칭) → `[a,b]` | ✅ 별칭 문법 차이 확인 |
| d7 | `map_agg(k, v)` → **MAP** `{a=1, b=2}` | `ARRAY_AGG(STRUCT(k, v))` → `[{"k":"a","v":1},...]` | ⚠ 동치 아님 — **재설계** |

## 결론

1. 배열/문자열/식별자 매핑 7종 실측 동치.
2. `element_at` 의 **음수 인덱스**는 BQ 에 직접 대응이 없고,
   `ARRAY_REVERSE(arr)[SAFE_OFFSET(0)]` (또는 `arr[SAFE_OFFSET(ARRAY_LENGTH(arr)-1)]`)
   로 대체 — 전자를 실측 검증.
3. **MAP 타입은 BQ 에 없음** 실측 확정. `map_agg` 류를 만나면 STRUCT ARRAY 로
   재설계하고, 키 조회(`m['a']`)는 `(SELECT v FROM UNNEST(arr) WHERE k='a')` 패턴
   또는 JSON 화 등 소비 패턴에 맞춰 케이스별 설계.

## 반영

- 변환표: 더블쿼트 식별자·REGEXP_LIKE·ELEMENT_AT·CARDINALITY·SEQUENCE·UNNEST 별칭·MAP 계열 행 ✅ 승격, ELEMENT_AT 비고에 음수 대체식 추가 (2026-09-03)
