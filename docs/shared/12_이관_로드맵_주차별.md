# 12. GCP 이관 로드맵 (주차별 태스크 리스트)

> 팀장님 리포팅용 시간순 태스크 리스트. Phase 1 (dev, 우리 팀) → Phase 2 (prod, DE 팀).
> DE 온보딩은 prod 이관 완료 후 (dev pipeline 이 prod 랑 상이하므로).

## 개요

- **Phase 1 (개발환경)**: 인프라 · Provider · 파일럿 · 표준 확립 — 우리 팀 (다이애나 팀) major deliverable
- **Phase 2 (운영환경)**: 우리 팀이 prod 이관 완료 → DE 온보딩 → DE 자율 이관 → 검증 → 소비자 이관 → cutover
- **Phase 2 게이트**: prod BQ raw 수집 완료 (⚠ 타팀 의존, 일정 확정 필요)

## 논리 흐름 (왜 이 순서인가)

**Phase 1 = 우리 팀만**
DE 참여 없이 파일럿 이관 · Provider · 도구 준비. Dev pipeline 이 prod 랑 상이해서 DE 온보딩 대상 부적합.

**Phase 2 초기 = 우리 팀이 prod 시동**
prod Composer + 우리 담당 ETL 을 prod 이관 완료. DE 가 온보딩할 때 볼 수 있는 real prod pipeline 준비.

**Phase 2 중반 = DE 온보딩 + 자율 이관**
Real prod ETL 로 DE 워크샵 · pair 프로그래밍. 이후 팀별 자율 이관.

**Phase 2 후반 = 검증 · 소비자 이관 · Legacy 정리**
DE 이관 결과 검증 → 서비스 · 대시보드 재연결 → Neptune shutdown.
