# Presto → BigQuery 변환 검증 기록

neptune-to-dbt 스킬의 변환표(`references/presto-to-bq.md`)에 있는 케이스들을
**실제 양쪽 엔진에서 실행해 검증한 상세 기록**.

- 스킬 쪽 표는 결론(매핑 + 한 줄 비고)만, **여기는 검증 쿼리 전문·실측 결과·판단 근거**까지.
- 케이스 하나 = 문서 하나 (`N_케이스명.md`). 검증 완료되면 스킬 표의 해당 행을 ✅ 로 승격.
- 실행 환경: Presto = adhoc 클러스터 / BigQuery = `dev-dp-project-354904` (QA)
- **세션 타임존 주의**: Neptune ETL 은 세션 TZ **UTC** 로 실행된다
  (`run_presto_sql_khp.sh UTC` — athlon 코드 확인). Hue 는 KST 세션이므로,
  TZ-민감 케이스(NOW, CURRENT_DATE, timestamp 캐스팅류)는 Hue 검증 결과가
  ETL 실행과 다를 수 있다 → 검증 쿼리에 `SELECT current_timezone()` 을 포함해
  세션을 기록하고, ETL 재현 검증은 UTC 세션에서. DATE 리터럴 기반 케이스
  (요일/주 시작/나눗셈 등)는 세션 TZ 무관이라 Hue 로 충분.

## 디렉토리

- **함정케이스 검증/** — 문법 에러 없이 결과가 조용히 달라지는 것들 (스킬 표 ⚠ 섹션)
- **함수매핑 검증/** — 이름/문법이 달라 바꿔야 하는 함수들 (날짜/타입/문자열/집계 섹션)
