# 3. 주 시작 — date_trunc('week') 의 시작 요일이 다르다

- 검증일: 2026-09-03
- 검증자: diana (Presto: Hue/adhoc — DATE 리터럴 기반이라 세션 TZ 무관 / BigQuery: `dev-dp-project-354904`)
- 분류: ⚠ 조용히 결과가 달라지는 함정 (문법 에러 없음)

## 무엇이 다른가

| | Presto `date_trunc('week', d)` | BigQuery `DATE_TRUNC(d, WEEK)` |
| --- | --- | --- |
| 주 시작 | **월요일** (ISO) | **일요일** (기본값) |

주간 집계(`GROUP BY date_trunc('week', ...)`)를 그대로 옮기면 문법 에러 없이
**주 경계가 하루 밀린 집계**가 나온다 — 일요일 데이터가 다른 주로 들어감.

## 검증 쿼리와 실측 결과

기준일: 2026-09-06 (일요일)

**Presto:**

```sql
SELECT date_trunc('week', DATE '2026-09-06') AS w
-- 결과: 2026-08-31 (그 주 월요일)
```

**BigQuery:**

```sql
SELECT
    DATE_TRUNC(DATE '2026-09-06', WEEK)         AS w1,  -- 결과: 2026-09-06 (일요일 시작 — 자기 자신)
    DATE_TRUNC(DATE '2026-09-06', WEEK(MONDAY)) AS w2   -- 결과: 2026-08-31 (presto 동치)
```

## 결론

1. **함정 성립**: 일요일 입력에서 presto 는 전주 월요일, BQ 기본은 당일.
2. **동치 변환 (검증됨)**: `DATE_TRUNC(d, WEEK(MONDAY))` — 항상 `(MONDAY)` 를 명시할 것.
3. 관련: `EXTRACT(WEEK FROM d)` / `FORMAT_DATE('%W')` 등 주차 번호 계열도 같은
   시작 요일 문제가 있을 것 — 주차 번호를 쓰는 쿼리를 만나면 별도 검증 (미실측).
